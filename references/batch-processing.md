# 批次與檔案處理

依功能選取適用項目，將結果寫入規格、設計或契約。數值與政策須有來源；引用及驗收依 [authoring-rules.md](authoring-rules.md)。

## 檔案規格

| 面向 | 檢查內容 |
| --- | --- |
| 格式 | 類型、編碼與 BOM、換行、分隔／跳脫、固定長度的字元／位元組單位、表頭／尾、版本及不支援結果 |
| 欄位 | 型別、必填、空值、長度、金額單位／幣別／精度／捨入、日期格式、筆數與金額控制總數；格式與業務驗證的時機及責任 |
| 邊界 | 空檔、只有表頭、截斷、重複列、非法字元、多餘資料及內容改動的處理 |
| 完成條件 | 傳輸、受理、執行與終局完成各自的證據、回應、狀態及失敗結果 |
| 識別與時間 | 檔案、批次、資料列及執行識別的關係；業務／執行日期、時區、截止時間與等於截止點的結果；跨日及假日依據 |

## 重複處理

先區分觸發意圖，再定義處理方式：

| 事件 | 檢查內容 |
| --- | --- |
| 重複提交 | 重複的認定、重用結果或拒絕條件、相同鍵但內容不同的結果 |
| 主動重送 | 原批次查詢／重送或更正後的新意圖、原批次關聯、權限與已完成資料處理 |
| 系統重試 | 錯誤與前提、操作識別、次數／間隔／期限依據、停止條件及耗盡結果 |
| 重新執行 | 全批或失敗列、執行識別沿用／新建、成功結果重用、外部副作用防重與核對 |

- **冪等**：相同業務操作重複執行仍維持約定結果。定義鍵的組成、作用範圍、保存／失效條件、結果重用及並行重複請求的結果。
- **結果不明**：逾時或斷線仍可能已完成；與確定未產生副作用分開處理，先查證外部查詢／核對契約，再決定恢復方式。
- **執行保證**：exactly-once（恰好一次）須有外部契約支持；重送指令本身不構成防重。

## 交易與恢復

- **處理單位**：定義整批失敗、逐筆失敗、部分成功與略過，區分開始前拒絕及可繼續的錯誤，說明最終狀態計算。
- **交易邊界**：選定整檔、分段或逐筆，說明提交資料、可見時機及失敗保留／回滾範圍。
- **外部副作用**：定義提交與扣款／通知的順序、結果不明處理、核對及補償責任；本地回滾不能代表外部撤銷。
- **補償**：查明可逆性、觸發條件、權限、失敗結果與核對依據。
- **中斷恢復**：涵蓋提交前、提交後未更新檢查點、外部完成但本地未記錄；明定繼續執行的判定者及防止遺失／重複的方法。
- **檢查點**：記錄已確定結果、與提交的關係及重啟位置；僅有最後讀取列號不足以證明完成。
- **並行**：定義分割鍵、順序、競爭資源、同批／同帳戶重疊限制及彙總時機；需要時才展開鎖定設計。

## 結果核對

- 定義受理、成功、失敗、略過及待定筆數的包含／互斥關係與核對等式，分清業務筆數及重試次數。
- 金額彙總須包含幣別、單位、精度、涵蓋狀態及對帳來源；操作成功仍須符合帳務核對要求。
- 定義錯誤資料的下載資格、定位資訊與錯誤含義，保持查詢、通知及檔案內容一致。

## 安全與營運

- **權限**：提交、查詢、下載、重送／重跑與補償的角色及資料範圍；雙人覆核依適用規範。
- **資料保護**：敏感資料的收集、遮罩、存取、傳輸與儲存限制；稽核涵蓋操作者、批次、執行及重要結果。
- **保存**：原始、中間及失敗檔的進入、暫存、封存、下載與刪除；保存期間及清除方式須有依據。
- **容量**：檔案大小、筆數、尖峰量、處理時間及記憶體限制的來源與量測條件。
- **監控**：區分未受理、等待、執行中、停滯、結果不明與失敗，依既有規範明定通知對象、操作責任及人工介入方式。
