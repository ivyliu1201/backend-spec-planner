# 批次與檔案處理

按功能選用，結果歸入規格、設計或契約；來源與驗收依 [authoring-rules.md](authoring-rules.md)。

## 檔案規格

- **格式**：類型、編碼／BOM、換行、分隔／跳脫、固定長度的字元／位元組單位、表頭／尾、版本及不支援結果。
- **欄位**：型別、必填、空值、長度、金額單位／幣別／精度／捨入、日期格式、筆數及金額控制總數。
- **驗證**：格式與業務檢查的時機及責任。
- **邊界**：空檔、僅表頭、截斷、重複列、非法字元、多餘資料及內容改動。
- **完成**：傳輸、受理、執行及終局的證據、回應、狀態與失敗結果。
- **識別**：檔案、批次、資料列與執行識別的關係。
- **時間**：業務／執行日期、時區、截止點含等號的結果、跨日及假日依據。

## 重複處理

| 事件 | 定義內容 |
| --- | --- |
| 重複提交 | 判定方式、結果重用／拒絕、同鍵異內容的結果 |
| 主動重送 | 原批次查詢／重送或更正後新意圖、關聯、權限與已完成資料處理 |
| 系統重試 | 錯誤與前提、操作識別、次數／間隔／期限、停止及耗盡結果 |
| 重新執行 | 全批或失敗列、執行識別、成功結果重用、副作用防重與核對 |

- **冪等**：重複操作維持約定結果；定義鍵、範圍、保存／失效、結果重用及並行結果。
- **結果不明**：逾時或斷線仍可能已完成；依外部查詢／核對契約查證後決定恢復方式。
- **執行保證**：exactly-once（恰好一次）須有外部契約支持。

## 交易與恢復

- **處理單位**：整批／逐筆失敗、部分成功及略過；定義拒絕、繼續與終局計算。
- **交易邊界**：整檔、分段或逐筆；定義提交資料、可見時機及失敗保留／回滾。
- **外部副作用**：提交與扣款／通知順序、未知結果、核對及補償責任；本地回滾不代表外部撤銷。
- **補償**：可逆性、觸發條件、權限、失敗結果及核對依據。
- **中斷恢復**：涵蓋提交前、提交後未更新檢查點、外部完成未記錄；定義續作責任及防遺失／重複措施。
- **檢查點**：對應已確定結果、提交與重啟位置；讀取列號不代表完成。
- **並行**：分割鍵、順序、資源競爭、同批／同帳戶重疊限制及彙總時機；鎖定按需設計。

## 結果核對

- 定義受理、成功、失敗、略過及待定筆數的包含／互斥關係與核對等式，分開業務筆數及重試次數。
- 依幣別、單位、精度、涵蓋狀態及對帳來源核對金額彙總。
- 定義錯誤資料的下載權限、定位與含義，保持查詢、通知及檔案一致。

## 安全與營運

- **權限**：提交、查詢、下載、重送／重跑及補償的角色與資料範圍；覆核依適用規範。
- **資料保護**：收集、遮罩、存取、傳輸及儲存限制；稽核操作者、批次、執行與結果。
- **保存**：原始、中間及失敗檔的進入、暫存、封存、下載、刪除、期限與清除依據。
- **容量**：檔案大小、筆數及尖峰批次量；量測依[效能與容量](design-rules.md#效能與容量)。
- **監控**：區分未受理、等待、執行中、停滯、未知及失敗；定義通知對象、操作責任與人工介入。
